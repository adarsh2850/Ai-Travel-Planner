# SarthiAI – AI Travel Planner ✈️

SarthiAI is an AI-powered travel planning web application that helps users
create personalized travel itineraries based on their destination, travel
duration, budget, interests, and preferences.

## 🚀 Features

- 🤖 AI-powered personalized travel itinerary generation
- 📍 Destination and location-based recommendations
- 🗺️ Interactive maps and location information
- 🌤️ Weather information for travel destinations
- 💰 Budget-based trip planning
- 🏨 Hotel and accommodation recommendations
- 🍴 Food and restaurant recommendations
- 📅 Day-wise travel itinerary
- 🔐 User authentication and authorization
- 💾 Save and manage travel plans
- 📱 Responsive and user-friendly interface
